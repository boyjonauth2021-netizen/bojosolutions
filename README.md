# Bojo Solutions

Public shelf for the websites, apps and games finished by Boyjonauth Kevin.

The home page opens onto three catalogues in that order — **Websites**, **Apps**, then **Games** — each with its own page of previews and links. Drafts and empty repositories are left off.

## Run it locally

```bash
npm install
npm run dev
```

The dev server listens on port 4327.

## GitHub Pages

The site is published with GitHub Actions to:

https://boyjonauth2021-netizen.github.io/bojosolutions/

Pages is set to build from the workflow in `.github/workflows/pages.yml`. No custom domain is attached. When a domain is registered later, add it in the repository Pages settings.

## Catalogue

The cards are compiled from the public repositories under `Bojo2025` and `boyjonauth2021-netizen` that were updated from April through November 2026 and that actually ship a site or a complete app.
